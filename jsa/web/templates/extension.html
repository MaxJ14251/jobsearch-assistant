Install it

  1. In Chrome, open chrome://extensions and turn on Developer mode.
  2. Choose Load unpacked and pick the extension folder of this project.
  3. Open the extension's options, paste the key from above, and check the dashboard port (8765).

On an application page it fills what it can, outlines required fields it left empty, and lists what it filled and from where. Salary is never filled. When you have pressed the page's Submit, “I submitted this” in its panel records the application here.
